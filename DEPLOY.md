## ⚡ Quick Deployment Steps

### 1. Push to GitHub/GitLab

```bash
# If not already pushed
git remote add origin <your-repo-url>
git push -u origin master
```

### 2. Deploy to Render

1. **Go to Render Dashboard**
   - https://dashboard.render.com

2. **Create Blueprint Instance**
   - Click "Blueprints" → "New Blueprint Instance"
   - Connect your repository (GitHub/GitLab)
   - Select the SecureMailScope repository

3. **Review Services**
   Render will detect 5 services from `render.yaml`:
   - ✅ Backend API (Web Service)
   - ✅ Celery Worker (Background Worker)
   - ✅ Frontend (Static Site)
   - ✅ PostgreSQL (Database)
   - ✅ Redis (Key-Value Store)

4. **Confirm Plans**
   - Backend API: **Standard** ($25/mo)
   - Worker: **Standard** ($25/mo)
   - Frontend: **Starter** (Free)
   - PostgreSQL: **Standard** ($20/mo)
   - Redis: **Standard** ($10/mo)
   - **Total: ~$80/mo**

5. **Click "Apply"**
   - Services will start deploying
   - Wait 5-10 minutes for first deployment

### 3. Update CORS (IMPORTANT!)

After deployment completes:

1. **Get Frontend URL**
   - Note your frontend URL (e.g., `https://securemailscope-frontend.onrender.com`)

2. **Update Backend CORS**
   - Navigate to `securemailscope-api` service
   - Go to Environment settings
   - Update `CORS_ORIGINS` to your actual frontend URL
   - Save (triggers redeploy)

### 4. Get Admin Credentials

1. Navigate to Backend API service settings
2. Find `ADMIN_PASSWORD` environment variable
3. Copy the auto-generated password

### 5. Test Deployment

1. **Open Frontend**
   - Visit your frontend URL
   - Login with:
     - Username: `admin`
     - Password: `<ADMIN_PASSWORD from step 4>`

2. **Upload Test PCAP**
   - Use `sample_pcaps/smtp_starttls_demo.pcap`
   - Upload via dashboard
   - Wait for analysis completion
   - Verify Phase 2 → 3 → 4 pipeline runs

3. **Verify Results**
   - ✅ Security findings displayed
   - ✅ Intelligence report generated
   - ✅ Evidence hash (SHA-256) shown

## ⚠️ Important Notes

1. **First Deployment**
   - Takes 5-10 minutes
   - Backend runs migrations automatically (`alembic upgrade head`)
   - Worker starts after backend is healthy

2. **CORS Configuration**
   - MUST update CORS_ORIGINS after deployment
   - Use exact frontend URL (including `https://`)
   - Without this, frontend cannot communicate with backend

3. **Admin Password**
   - Auto-generated by Render (secure random string)
   - Find in Backend API environment variables
   - Default username is always `admin`

4. **Storage Persistence**
   - 20GB persistent disks configured
   - Evidence survives service restarts
   - Backend and Worker have separate disks

5. **Large PCAP Testing**
   - After deployment, test with 133MB PCAP
   - Monitor worker logs during processing
   - Current limit: 500MB (MAX_PCAP_SIZE_MB)

## 🐛 Troubleshooting

### CORS Errors
```
Solution: Update CORS_ORIGINS to actual frontend URL
Backend Settings → Environment → CORS_ORIGINS
```

### Worker Not Processing
```
Solution: Check worker logs
Dashboard → securemailscope-worker → Logs
Verify Redis connection is healthy
```

### Migration Errors
```
Solution: Check pre-deploy logs
Backend deployment logs should show:
"Running upgrade ... -> 0006_fix_enums"
```

### TShark Not Found
```
Solution: Rebuild backend Docker image
Should see "TShark 4.4.18" in build logs
```

For full troubleshooting guide: `docs/RENDER_DEPLOYMENT.md`
